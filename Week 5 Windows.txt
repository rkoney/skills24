Learning Objectives
By the end of this week, you should be able to:

	•	Enter BIOS/UEFI settings.
	•	Set the boot device priority.
	•	Boot into Windows Setup.

Choose:
	•	Language
	•	Time and currency format
	•	Keyboard layout
Click:
Next → Install Now

Step 3 — Choose Edition
Select one:
Edition
Purpose

Installation Options:
Option
Description

GUI included

Minimal interface
Recommendation:
	•	Use Desktop Experience for beginners.
	•	Use Server Core for production security and performance.

Step 4 — Accept License Terms
	•	Check:
	•	“I accept the license terms”
	•	Click:
	•	Next

Step 5 — Select Installation Type
Choose:
	•	Custom: Install Windows only (advanced)

Step 6 — Configure Disk Partitions
	•	Select available disk.
	•	Create partitions if necessary.
	•	Click:
	•	Next
The installation process begins.

Step 7 — Configure Administrator Password

	•	Set a strong Administrator password.
	•	Sign in.
Password Best Practices:
	•	Minimum 12 characters
	•	Use uppercase, lowercase, numbers, and symbols
	•	Avoid dictionary words

2. Initial Server Configuration
2.1 Configure Computer Name
GUI Method
	•	Open:
	•	Server Manager
	•	Click:
	•	Local Server
	•	Select:
	•	Computer Name
	•	Click:
	•	Change
	•	Restart the server.
PowerShell Method
Rename-Computer -NewName "SRV-DC01" -Restart

2.2 Configure Static IP Address
GUI Method
	•	Open:
	•	Network Connections
	•	Right-click adapter → Properties
	•	Select:
	•	Internet Protocol Version 4 (TCP/IPv4)
	•	Configure:
	•	IP Address
	•	Subnet Mask
	•	Default Gateway
	•	DNS Server
PowerShell Method
New-NetIPAddress -InterfaceAlias "Ethernet" `
-IPAddress 192.168.1.10 `
-PrefixLength 24 `
-DefaultGateway 192.168.1.1
Configure DNS:
Set-DnsClientServerAddress -InterfaceAlias "Ethernet" `
-ServerAddresses 192.168.1.10

2.3 Configure Time Zone
PowerShell
Set-TimeZone -Name "Greenwich Standard Time"
Check current timezone:
Get-TimeZone

2.4 Enable Remote Desktop
GUI Method
	•	Server Manager
	•	Local Server
	•	Remote Desktop → Enable
PowerShell Method
Set-ItemProperty -Path 'HKLM:\System\CurrentControlSet\Control\Terminal Server' `
-name "fDenyTSConnections" -value 0
Enable firewall rule:
Enable-NetFirewallRule -DisplayGroup "Remote Desktop"

4. DNS Server Configuration
4.1 Install DNS Role
Install-WindowsFeature DNS -IncludeManagementTools

4.2 Create Forward Lookup Zone
GUI Method
	•	Open DNS Manager.
	•	Expand server.
	•	Right-click:
	•	Forward Lookup Zones
	•	Select:
	•	New Zone
	•	Choose:
	•	Primary Zone
	•	Enter zone name.
Example:
corp.local

4.3 Add Host Record
	•	Right-click zone.
	•	Select:
	•	New Host (A or AAAA)
	•	Enter:
	•	Name
	•	IP Address

4.4 Verify DNS
nslookup server01.corp.local

5. DHCP Server Configuration
5.1 Install DHCP Role
Install-WindowsFeature DHCP -IncludeManagementTools

5.2 Authorize DHCP Server
Add-DhcpServerInDC -DnsName "srv-dhcp01.corp.local"

5.3 Create DHCP Scope
Add-DhcpServerv4Scope `
-Name "Office Scope" `
-StartRange 192.168.1.100 `
-EndRange 192.168.1.200 `
-SubnetMask 255.255.255.0
Configure gateway:
Set-DhcpServerv4OptionValue `
-ScopeId 192.168.1.0 `
-Router 192.168.1.1
Configure DNS:
Set-DhcpServerv4OptionValue `
-ScopeId 192.168.1.0 `
-DnsServer 192.168.1.10 `
-DnsDomain corp.local

6. File Services and DFS Namespaces
6.1 Install File Services
Install-WindowsFeature FS-FileServer

6.2 Create Shared Folder
New-Item -Path "D:\SharedData" -ItemType Directory
Create SMB share:
New-SmbShare -Name "SharedData" -Path "D:\SharedData"

6.3 Install DFS Namespace
Install-WindowsFeature FS-DFS-Namespace -IncludeManagementTools

6.4 Configure DFS Namespace
	•	Open DFS Management.
	•	Right-click:
	•	Namespaces
	•	Select:
	•	New Namespace
	•	Enter server name.
	•	Define namespace name.
Example:
\\corp.local\Public

8. IIS (Internet Information Services)
8.1 Install IIS
Install-WindowsFeature Web-Server -IncludeManagementTools

8.2 Verify IIS Installation
Open browser:
http://localhost
You should see the IIS default page.

8.3 Deploy a Simple Website
Create Website Folder
New-Item -Path "C:\Websites\CompanySite" -ItemType Directory
Create Test Page
Set-Content -Path "C:\Websites\CompanySite\index.html" `
-Value "<h1>Company Website</h1>"
Create IIS Website
New-IISSite `
-Name "CompanySite" `
-PhysicalPath "C:\Websites\CompanySite" `
-BindingInformation "*:80:"

13. Troubleshooting Guide
DNS Issues
Symptoms
	•	Name resolution failure
	•	Clients cannot locate servers
Solutions
ipconfig /flushdns
Restart DNS service:
Restart-Service DNS

DHCP Issues
Symptoms
	•	Clients receive APIPA addresses (169.254.x.x)
Solutions
Check scope status:
Get-DhcpServerv4Scope
Restart DHCP service:
Restart-Service DHCPServer

IIS Issues
Symptoms
	•	Website inaccessible
Solutions
Verify IIS service:
Get-Service W3SVC
Restart IIS:
iisreset
