Debian Linux Administration Lab Manual

Duration: 4 Weeks
Skill Level: Beginner → Junior Linux Administrator

Primary platform used:
	•	Debian

Recommended virtualization environment for training:
	•	VirtualBox
	•	VMware Workstation

Using virtualization allows students to practice without damaging their primary system.

WEEK 2 LABS — System Administration

Lab 5: User and Group Management

Create Users
sudo adduser john
sudo adduser mary
Check users:
cat /etc/passwd

Create Groups
sudo groupadd developers
Add user to group:
sudo usermod -aG developers john
Verify group membership:
groups john

Lab 6: File Permissions

Create a test file:
touch project.txt
View permissions:
ls -l project.txt
Change permissions:
chmod 744 project.txt
Explanation:
7 = rwx
4 = r--
Change owner:
sudo chown john project.txt

Lab 7: Process Management

List processes:
ps aux
Real-time monitoring:
top
Install better monitoring tool:
sudo apt install htop
Run:
htop
Kill process example:
kill PID

Lab 8: Package Management

Update system:
sudo apt update
sudo apt upgrade
Install software:
sudo apt install nginx
Remove software:
sudo apt remove nginx
Search software:
apt search apache

Lab 9: File Sharing with Samba

Install Samba:
sudo apt install samba
Create shared folder:
sudo mkdir /shared
sudo chmod 777 /shared
Edit configuration:
sudo nano /etc/samba/smb.conf
Add:
[shared]
path = /shared
browseable = yes
read only = no
guest ok = yes
Restart service:
sudo systemctl restart smbd

Lab 10: NFS File Sharing

Install server:
sudo apt install nfs-kernel-server
Create shared directory:
sudo mkdir /nfs-share
Edit exports:
sudo nano /etc/exports
Add:
/nfs-share 192.168.1.0/24(rw,sync)
Restart service:
sudo systemctl restart nfs-kernel-server

Week 5 — Advanced Storage Management

Administrators must understand how to manage disks efficiently and safely.

Lab 22: Disk Identification and Management

Step 1: List Disks
lsblk
Example output:
sda      8:0   0 40G  0 disk
├─sda1   8:1   0 20G  0 part /
├─sda2   8:2   0 18G  0 part /home
└─sda3   8:3   0 2G   0 part [SWAP]
Another method:
sudo fdisk -l

Step 2: Create a New Partition

Start partition tool:
sudo fdisk /dev/sdb
Commands inside fdisk:
n   (new partition)
p   (primary)
1   (partition number)
w   (write changes)

Step 3: Format Partition

Create filesystem:
sudo mkfs.ext4 /dev/sdb1

Step 4: Mount Disk

Create mount directory:
sudo mkdir /data
Mount disk:
sudo mount /dev/sdb1 /data
Verify:
df -h

Step 5: Permanent Mount

Edit filesystem table:
sudo nano /etc/fstab
Add:
/dev/sdb1   /data   ext4   defaults   0   2

Lab 23: Logical Volume Manager (LVM)

LVM allows flexible disk management.

Step 1: Install LVM tools
sudo apt install lvm2

Step 2: Create Physical Volume
sudo pvcreate /dev/sdb1

Step 3: Create Volume Group
sudo vgcreate data_vg /dev/sdb1

Step 4: Create Logical Volume
sudo lvcreate -L 5G -n backup_lv data_vg

Step 5: Format and Mount
sudo mkfs.ext4 /dev/data_vg/backup_lv
Mount:
sudo mount /dev/data_vg/backup_lv /backup

Lab 24: RAID Storage

RAID improves data redundancy and performance.

Install RAID tools:
sudo apt install mdadm
Create RAID 1 (mirror):
sudo mdadm --create /dev/md0 --level=1 --raid-devices=2 /dev/sdb /dev/sdc
Check status:
cat /proc/mdstat
